# Roadmap

| Division | Steps | Description |
|---|---|---|
| 00 Scope & Decisions | 1–4 | Nail down what Constimator is, who it's for, and the key product/data decisions before building |
| 01 Foundations | 5–14 | Stand up the core app structure, data model, and UI scaffolding it's built on |
| 02 Estimating Engine | 15–22 | Build the core cost-estimation logic and calculations |
| 03 Hardening | 23–30 | Test, fix edge cases, and shore up reliability of the estimating engine and UI |
| 04 Business Layer | 31–34 | Add the business-facing features on top (proposals, branding, sharing, etc.) |
| 05 Scale & Reliability | 35–37 | Prepare the app for real-world use at scale |
